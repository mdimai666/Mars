# codebase-memory MCP — архивная заметка (не используется)

**Статус (2026-11-12):** MCP-сервер `codebase-memory` (граф кода) был подключён к агенту,
но агентом фактически не использовался. Секция о нём удалена из `QWEN.md` по решению владельца;
в текущей конфигурации (`.qwen/settings.json`) сервер не значится. Файл хранит накопленный
опыт на случай, если к графу кода вернутся. Сейчас структурный поиск — grep по конкретным
директориям (см. `ai/ProjectStructureGuide.md`, раздел «Агентам»).

## Что это было

- Граф кода через MCP `codebase-memory`; имя проекта индекса выводилось из пути клонирования
  (зависело от места открытия репо).
- Переиндексация после больших внешних изменений — `index_repository` (~3–4 минуты).
- Инструменты: `trace_path` (вызывающие/вызываемые со счётчиками), `search_graph`/`search_code`
  (поиск с дедупликацией по функциям), `get_architecture` со скоупом `path` (обзор + хотспоты),
  `query_graph` (пофайловые агрегации, карта потребителей пакета).

## Когда имело смысл использовать

- Структурный анализ вместо grep: «кто использует тип/метод», радиус влияния изменений.

## Грабли (фронт — слабое место)

- razor-разметка (`.razor`) не индексировалась — только `.razor.cs`; фронтовые зависимости
  (`Mars.Admin`, `Mars.Admin.Framework`) проверять grep'ом.
- Generic-инстанциации и типы свойств record часто не давали USAGE-рёбер: «0 внешних» из графа —
  только гипотеза о мёртвом коде, подтверждать grep'ом.
- Атрибуты попадали в граф как DECORATES, а не USAGE.

## Известные баги (проверено 2026-08-28)

- `NOT x.file_path STARTS WITH '...'` молча возвращал 0 строк (любая форма). Обход: два запроса
  (все пользователи / внутренние) и вычитание.
- `split()` не поддерживался (ошибка `unsupported function`); доступны только функции из текста
  ошибки (count/sum/avg/min/max/collect, toLower/toUpper/toString/…, labels/type/id/keys/properties).
- Обход рёбер и мульти-типовые паттерны `[:CALLS|CALL_REFERENCE|USAGE]` работали
  (после обновления сервера 2026-08-28).
- Сырые результаты MCP пользователю не показывать — только сжатый итог.
