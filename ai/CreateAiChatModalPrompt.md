Я хочу в админке сделать чат с ИИ агентом, который выполняет все задачи по сайту.
Он будет в виде модального окна внизу по центру на 1/9 экрана типа. Вызываем его по нажатию кнопки "ИИ агент". Кнопка тоже внизу по центру, как кнопка сири, но его иожно по зажатию двигать по краям экрана.

Я вдохновляюсь Qwen Code Cli, он тоже пусть будет подобно терминалу.

1. Создаем новый проект Mars.AiChat (.Front, .Shared, .Host, .Host.Shared) который подключается к Mars.WebApp.
   - Проект создай в /src/Mars.Modules. Посмотри аналогию в \src\Mars.Modules\Mars.SemanticKernel
   - к Mars.WebApp подключи .Host а в AppAdmin .Front. Если кто то захочет использовать его то через .Host.Shared
2. Создай настроку подключения к ИИ сервисам как к OpenAi,Qwen, Deepseek, Ollama и другие популярные.
    - PluginExamplePlugin.cs пример создания и настройки 
3. Использьзуй Microsoft Agent Framework для создания агента. 
    - уже существующий Mars.SemanticKernel считай устаревшим.
    - Он должен принимать запросы от пользователя и возвращать ответ.
    - Пусть он хранит чат пока в HybridCache.
    - используй контроллеры а не минимал апи.
    - в проекте уже есть SignalR.
    - агент выполняет не один промпт а как harness множесто. 
4. Посмотри как подключаются глобальные компоненты \src\AppAdmin\App.razor мой пример AIToolsContainer
    - В чате/терминале есть кнопка остановить, сменить чат.
    - как и в терминале набираешь текст и Enter.
    - Еще сделай чтобы он мог у пользователя уточнять вопросы.

Как он будт использоваться:
- Например я ему говорю создать пост на такую то тему. От открывает страницу созданий поста и начинает писать пост.
- Говорю поменяй имя сайта в настройках - меняет.
- Создает любой контент, пост, пользователя итд.
- Или на открытой странице(он знает на какой он странице) говорю заполнить, он заполняет.

Пока сценарии и скиллы оставим. Для начала сделаем просто чтобы он мог менять настройки сайта.
