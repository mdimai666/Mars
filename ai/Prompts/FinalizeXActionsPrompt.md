XActions - по задумке это универсальный интерфейс для всех действий, которые можно сделать на платформе. Вдохновлен Command Palette из vscode.

У них есть уникальный Id (как имя пакета author.package.name), и аргументы (массив строк).
Можно регестировать и в плагинах.
Вызываются так и просто нажатием кнопок в админке, или можеи использовать ИИ агент.
Бывают системными или которые может видеть пользователь.

Сценарии применения:
- На сайте сброса кеша. Создается XAction и вешается на кнопку (уже есть).
- Вешается, чтобы просто открывать страницы в админке XLink.
- Создается сценарий создания политики конфиденциальности, он вызывает ИИ чат просто с промптом.
- Еще есть у Nodes провайдеры, которые регистируют ноды как команды в админке.
- Если там нужны аргументы при вызове из админки, то он должен показать форму заполнения. Если переданы аргументы то можно вызвать и без формы. Но думаю это надо как то отдельно сделать чтобы не усложнять сами XActions.
- Если обязательных аргументов нет, то просто исключение.
