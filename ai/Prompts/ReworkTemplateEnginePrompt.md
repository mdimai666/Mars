## Про то как сейчас работает

Посмотри WebPage.cs я хотел придумать такую систему похожей с Blazor pages.
```
@page "/url/{param}" # это ссылка и их быть может не один
@layout "layout/base" # какой layout использовать
@cache 10m # кешировать

# и например такой способ запроса данных. И тут не только данные но и подключенные функции вызывать. Например есть http запросы.
# двойной знак == в данном случае eval типа но в c#
{{#context}}
page == int.Parse(_req.Query["page"]??"1")
table = ef.post.OrderByDescending(CreatedAt).Table(page,10)
posts == table.Items
{{/context}}

```

context - пока жедать не будем, сосредоточимся пока на отрисовке.

атрибуты конечно в самой странице не отрисовываются.

в корне есть _root.hbs например это точка входа от него все начинает отрисовываться, но у папок может быть свой _root если он не просто layout меняет а все.

Публичной папкой является по умолчанию wwwroot
