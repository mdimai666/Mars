# Логирование

Логи приложения пишутся в дневные файлы `data/logs/app_yyyy-MM-dd.log` (NReco.Logging.File).
В админ-панели страница `/builder/debug` («Debug») показывает логи бесшовно по дневным файлам,
с фильтрами по уровню и периоду.

## Конфигурация

Настраивается секцией `Logging` в appsettings (в Docker — файл `config/appsettings.Production.json` на томе):

```json
"Logging": {
    "LogLevel": {
        "Default": "Information"
    },
    "File": {
        "LogLevel": {
            "Default": "Warning"
        },
        "RetentionDays": 30
    }
}
```

- `Logging:LogLevel` — общий уровень для всех провайдеров логирования (консоль и т.д.).
- `Logging:File:LogLevel` — уровень именно **файла** логов: по умолчанию пишется только `Warning` и выше.
- `Logging:File:RetentionDays` — период хранения в днях. Системная джоба `logs-cleanup`
  удаляет файлы старше периода: раз в день в 03:00 и при старте приложения.

## Изменение уровня без перезапуска

Уровень логирования **применяется без перезапуска**: сохраните изменённый appsettings —
значение подхватится автоматически (конфигурация загружается с reload, правила фильтрации
перечитываются при следующей записи лога). Это касается и уровня файла (`Logging:File:LogLevel`),
и общего уровня (`Logging:LogLevel`).

Пример: чтобы временно собирать в файл более подробные логи, поставьте
`"Logging:File:LogLevel": { "Default": "Information" }` — новые записи уровня Information
начнут попадать в файл сразу, перезапуск не нужен.
