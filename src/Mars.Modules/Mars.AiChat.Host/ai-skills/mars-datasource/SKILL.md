# Источники данных Mars (file, rest)

Кроме SQL-баз (скилл `mars-sql`) в Mars подключаются источники kind=file (CSV/XLSX) и kind=rest
(внешние API: WordPress, OpenAPI и любые HTTP-эндпоинты). Инструменты:

- `list_data_sources` — список источников: slug, kind, возможности (write — источник можно писать);
- `get_source_schema(slug, filter)` — каталог источника: у file — файлы/листы с типами колонок,
  у rest — операции `METHOD путь` с параметрами (где передаётся, тип, обязательность, enum, default);
  записывающие операции помечены `(запись)`; на больших каталогах передавай filter;
- `run_query(slug, objectId, query, parametersJson)` — выполнить запрос.

## file-источники

- `objectId` — файл или `файл#Лист` из схемы; `query` — ОДНО выражение-предикат Dynamic LINQ
  (фильтр строк), пустой — все строки. Цепочки `rows.Where(...)` не работают — пиши только условие:
  `age > 30 && name.StartsWith("A")`.
- Значения ячеек — текст; для чисел/дат используй null-безопасные функции:
  `Val.Num(age) > 30`, `Val.Dec(price)`, `Val.Str(name)`, `Val.Date(born)`, `Val.Flag(active)`,
  `Val.Id(code)`. Имена функций и колонок — с учётом регистра.
- Сортировку и проекцию текстом не задать — только фильтр. Нужно больше колонок/порядок — фильтруй
  и читай результат как есть.
- file-источники только для чтения: запись не поддерживается.
- Результат обрезается до 25 строк — сужай предикат.

## rest-источники

- `objectId` — операция из схемы, формат `GET /wp/v2/posts` (метод + путь);
- `parametersJson` — JSON-объект имя→значение из схемы операции, например `{"page":"2","per_page":"10"}`;
  обязательные параметры (помечены в схеме) передавай всегда;
- ответ — строки как JSON; если источник сообщил общее число записей (например WordPress), оно приходит
  в поле total — используй его для пагинации;
- записывающие операции (POST/PUT/PATCH/DELETE, в схеме помечены `(запись)`) выполняй ТОЛЬКО после того,
  как показал пользователю операцию с параметрами и получил подтверждение через ask_user; исключение —
  пользователь явно разрешил запись без подтверждений;
- никогда не выводи доступы и токены источника.

## SQL-источники

kind=sql (включая slug "default" — основная база Mars) — через `execute_sql`, правила в скилле `mars-sql`.
