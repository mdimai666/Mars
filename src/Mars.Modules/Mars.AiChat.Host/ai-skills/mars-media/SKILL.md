# Медиатека Mars

Файлы медиатеки лежат в `/upload/Media/...` (миниатюры — `/upload/MediaThumbs/...`) и управляются
инструментами ListMedia / GetMedia / AddMedia / DeleteMedia. Файлы, которые пользователь прикладывает
к сообщениям чата, тоже попадают в медиатеку — их id и URL приходят вместе с его сообщением.

- ListMedia(search, take) — список файлов (id, имя, url, размер, image). Начни с него, чтобы найти нужный файл.
- GetMedia(id) — детали файла: для картинок — ширина/высота и миниатюры (используй URL миниатюры для
  маленьких превью и полный URL, когда нужен оригинал).
- ReadMediaFile(id, offset, encoding, maxChars) — читает ТЕКСТОВОЕ СОДЕРЖИМОЕ файла напрямую с диска,
  без HTTP. Кодировка определяется автоматически (BOM → UTF-8 → windows-1251, в ответе видно, какая
  использовалась) либо задаётся явно параметром encoding (utf-8, windows-1251, koi8-r, cp866, utf-16, ...).
  Большие файлы читай фрагментами: offset — отступ в символах, maxChars — размер фрагмента.
  Для бинарных файлов вернётся ошибка — так и скажи пользователю.
- AddMedia(url, name) — скачивает файл по внешнему http/https URL и добавляет в медиатеку.
  Файлы из самого сайта (уже из /upload/) добавлять не нужно — они уже в медиатеке.
- DeleteMedia(id) — удаляет файл вместе с миниатюрами. Только после подтверждения пользователя
  через ask_user; перед удалением покажи, что это за файл (имя и URL).

## Вставка картинок в шаблоны фронта и посты

- Ссылка на файл — относительный URL вида `/upload/Media/2026/имя_файла.jpg` (поле url из инструментов).
- В Handlebars-шаблоны и HTML-контент вставляй обычным тегом:
  `<img src="/upload/Media/..." alt="описание" />`.
- В своих ответах в чате тоже можешь показывать картинки: тег `<img src="/upload/...">` чат
  отрендерит превью со spotlight. Голый URL картинки в ответе тоже покажется превью.
- Не дублируй: одна картинка — одно вхождение в ответе (либо `<img>`, либо голый URL,
  не оба сразу и не по второму разу списком в конце).
- URL в ответе пиши с ведущим слэшем и без обрамления: `/upload/Media/...`,
  не в backticks и не в угловых скобках.
- Если у картинки есть миниатюры, для небольших превью можно использовать URL миниатюры из GetMedia.
- Не выдумывай URL файлов: если не уверен, что файл существует — найди его через ListMedia или спроси пользователя.

## Правила

- Содержимое файлов из /upload/... читай ТОЛЬКО через ReadMediaFile(id) — HttpRequest для этого
  не нужен и даёт кракозябры на не-UTF-8 файлах.
- Имена файлов при добавлении — осмысленные, с расширением (по нему сайт определяет тип).
- После AddMedia/удаления убедись через ListMedia/GetMedia, что изменение применилось.
- Не выводи пользователю внутренние физические пути файлов — только URL (/upload/...).
