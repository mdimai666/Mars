# Посты

## Тип поста — DescribePostType

Перед созданием или обновлением поста с метаполями вызови DescribePostType(type):
состав метаполей (ключи, типы, кратность, обязательность), варианты Select (ключи),
статусы (slug), редактор контента и поле картинки поста (imageFieldKey).
Не выдумывай ключи полей, варианты и статусы — бери их только из DescribePostType/GetPost.

## Создание и обновление (страница не нужна)

- CreatePost(type, title, contentText, tagsCsv, excerpt, metaJson, status) — создаёт пост
  (по умолчанию черновик), в результате ссылка на страницу редактирования — передай её пользователю.
- UpdatePost(postId, title, contentText, tagsCsv, excerpt, status, metaJson) — обновляет пост.
  Передавай ТОЛЬКО меняемые поля (пустая строка = не менять; `-` в tagsCsv/excerpt = очистить).
  Это last-write-wins: запись заменяет данные целиком последними прочитанными значениями,
  поэтому сначала прочитай пост (GetPost) и не обновляй его серверно, пока пользователь
  правит этот пост в админке (несохранённые правки формы будут потеряны).
- GetPost — название, slug, статус, теги, анонс, язык, текст и значения метаполей (meta),
  а также imageFieldKey типа. Материализованные значения (варианты, файлы) приходят
  готовыми объектами — их id/ключи можно сразу использовать в metaJson.
- ListPosts — найти посты по типу.

### Формат metaJson (JSON-объект «ключ поля: значение»)

- String/Text — строка; Bool — true/false; Int/Long/Float/Decimal — число или строка-число;
- DateTime — строка ISO-8601;
- Select — КЛЮЧ варианта; SelectMany — массив ключей или список через запятую;
- Relation/File/Image — Guid объекта (файла, записи);
- множественные поля (multiple) — массив значений;
- поля с readOnly (вычислимые/выключенные) — не передавай; обязательные (required) поля
  нужны уже при создании — если значения нет, спроси пользователя.

## Картинка поста

Значение Image-поля — Guid файла из медиатеки:

1. картинка из интернета — AddMedia(url, name); уже есть в медиатеке — найди через ListMedia;
2. запиши Guid в Image-поле: ключ поля — imageFieldKey типа (или другое поле типа Image) —
   через metaJson у CreatePost/UpdatePost.

Не выдумывай Guid файлов — только из AddMedia/ListMedia/GetPost.

## Открытая страница редактирования поста

Если у пользователя открыта страница редактирования (pageContext указывает на неё), доступны
инструменты открытой страницы: GetOpenPageInfo / GetOpenPageFields / SetOpenPageField / SaveOpenPage.

- сначала вызови GetOpenPageInfo, затем GetOpenPageFields, чтобы увидеть текущие значения;
- меняй поля через SetOpenPageField; поле content — полный новый текст (для редактора блоков он будет разбит на абзацы);
- правь через страницу, а не серверным UpdatePost: изменения попадают в форму, пользователь их видит и сам сохраняет;
- если контент большой или содержит не только текст (картинки, вставки) — перед заменой уточни у пользователя через ask_user;
- НЕ сохраняй страницу (не вызывай SaveOpenPage), если пользователь явно не попросил сохранить;
- изменив поля, коротко сообщи, что поменялось, и напомни, что изменения надо сохранить.
