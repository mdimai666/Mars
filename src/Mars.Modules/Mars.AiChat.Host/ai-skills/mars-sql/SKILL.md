# SQL-доступ к базам данных

Инструменты: `list_data_sources` — список источников (slug, kind, драйвер, возможности); slug "default" —
основная база самого сайта Mars (посты, пользователи, настройки, метаданные); остальные slug с kind=sql —
настроенные внешние базы. Источники kind=file и kind=rest — не SQL: к ним работай по скиллу
`mars-datasource` (LoadSkill, если не загружен).

Правила:

- схему не выдумывай: перед запросами вызови `get_source_schema(slug, filter)` — для больших баз
  передавай filter (имя или часть имени нужных таблиц);
- диалект зависит от драйвера источника (psql, mssql, mysql) — учитывай различия
  (LIMIT/FETCH vs TOP/OFFSET-FETCH, кавычки идентификаторов, функции дат);
- запросы выполняй через `execute_sql`, один запрос за вызов; для SELECT всегда добавляй LIMIT
  (начни с 25) — ответ и так обрезается до 25 строк; если источник сообщил общее число записей,
  оно приходит в поле total;
- перед любым записывающим запросом (INSERT/UPDATE/DELETE/DROP/TRUNCATE/ALTER/CREATE) обязательно покажи
  пользователю точный SQL и получи подтверждение через ask_user; исключение — пользователь явно разрешил
  выполнять запись без подтверждений в рамках текущей задачи;
- после записи проверь результат запросом на чтение и сообщи число затронутых строк;
- никогда не выводи и не запрашивай connection strings.
