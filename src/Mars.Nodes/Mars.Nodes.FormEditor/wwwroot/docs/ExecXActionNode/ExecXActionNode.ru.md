# ExecXActionNode

Выполняет действие XAction на хост-машине.

## Свойства

| Свойство | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `CommandId` | `string` | `""` | Id выполняемой XAction |
| `Args` | `Dictionary<string, string>` | `[]` | Именованные аргументы вызова (`имя=значение`, по одному в строке) |

Результат (`XActResult`, включая эффекты) передаётся в payload выхода — что с ним делать,
решает сам поток, автоцепочки не выполняются.
