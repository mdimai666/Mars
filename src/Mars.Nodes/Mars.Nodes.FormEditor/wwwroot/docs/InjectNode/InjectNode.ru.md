# InjectNode

Запускает flow: вручную из редактора, из CLI, при старте или по расписанию.

## Поля

Нода отправляет сообщение со списком полей. У каждого поля:

- **Key** — идентификатор или dot-путь. `Payload` (без учёта регистра) уходит в `msg.Payload`;
  любой другой ключ — в контекст и доступен как `msg.<key>`.
- **Type** — тип значения: `int`, `long`, `float`, `double`, `decimal`, `bool`, `string`, `DateTime`,
  `Guid`, массивы (`int[]`, `string[]`, …) и `timestamp`.
- **Value** — разбирается согласно источнику значения (value kind):
  - `const` — литерал, парсится по типу. Массивы и объекты вводятся JSON-текстом.
    `timestamp` — unix-миллисекунды; пусто означает «сейчас».
  - `msg` — путь к полю входящего сообщения, например `Payload.Count` (резолвится как `msg.<path>`).
  - `expression` — C#-выражение (DynamicExpresso), например `msg.Payload.Count() + 1`.
    Доступные корни: `msg`, `GlobalContext`, `FlowContext`, `VarNode`, `env("KEY")`; LINQ поддерживается.
    Результат конвертируется в Type.

Порядок полей — только визуальный (drag & drop); контекст — это словарь.

Ошибка разбора или вычисления роняет ноду с именем поля и значением в сообщении.

У только что добавленной ноды одно поле по умолчанию: `Payload` типа `timestamp` (текущее время).

## Редактор значения

В форме значение вводится обычным текстом (`const`) или с префиксом `@` (`expression`),
например `@21 * 2` или `@msg.Payload.Count() + 1`. Поле, сохранённое с kind `msg`, отображается
как `@msg.<path>` и сохраняется обратно эквивалентным выражением. В режиме выражения доступны
автокомплит (`Ctrl+Space`), дерево полей (`Alt+Down`) и попап операций (`Alt+Up`);
для константы `DateTime` есть календарь (`F4`).

## Запуск при старте и расписание

- **Run at startup** + **Delay millis** — однократный запуск после старта ноды.
- **IsSchedule** + **cron mask** — Quartz cron-выражение, например `0/5 * * * * ?` — каждые 5 секунд.

## Пример JSON

```json
{
  "TypeId": "core.InjectNode",
  "Fields": [
    { "Key": "Payload", "VarType": "string", "ValueKind": "const", "Value": "Hello!" },
    { "Key": "status", "VarType": "string", "Value": "ok" },
    { "Key": "doubled", "VarType": "int", "ValueKind": "expression", "Value": "21 * 2" }
  ]
}
```

## CLI

`./mars.exe node inject <name|id>` — запускает ноду с пустым входящим сообщением
(поля по умолчанию дают текущий timestamp).
